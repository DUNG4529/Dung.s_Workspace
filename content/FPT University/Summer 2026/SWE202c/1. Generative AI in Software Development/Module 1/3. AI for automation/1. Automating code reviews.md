# Amazon Q Developer - Tự Động Hóa Code Review Cho Java

## Giới Thiệu

Hãy tưởng tượng bạn vừa viết một chương trình xét duyệt khoản vay (loan application) để kiểm tra tính đủ điều kiện của người dùng dựa trên độ tuổi và số tiền vay. Chương trình hoạt động, nhưng có thể thiếu kiểm tra đầu vào (input validation) hoặc tên biến không rõ ràng.

Theo cách truyền thống, bạn phải nhờ một senior developer review code của bạn — quá trình này có thể chậm, đặc biệt với dự án lớn.

Với **Amazon Q Developer**, công cụ AI tích hợp trong IntelliJ IDEA, bạn có thể:
- Phân tích code theo thời gian thực
- Phát hiện vấn đề và đưa ra đề xuất cải tiến
- Học các **best practices** để viết code sạch hơn, hiệu quả hơn

### Các Đề Xuất Cải Tiến

#### 1. Input Validation

**Vấn đề:** Code không kiểm tra input → nhận giá trị không hợp lệ (số âm, null)

**Giải pháp:** Thêm validation để đảm bảo dữ liệu đầu vào có ý nghĩa

```java
if (userAge < 0 || requestedLoanAmount < 0) {
    System.out.println("Invalid input. Age and loan amount must be positive.");
    return;
}
```

#### 2. Cải Thiện Tên Biến

**Vấn đề:** Tên biến như `age`, `loanAmount` không đủ mô tả

**Giải pháp:** Đổi tên rõ ràng hơn

```java
int userAge;              // thay vì age
double requestedLoanAmount; // thay vì loanAmount
```

> [!tip] LỢI ÍCH
> Tên biến rõ ràng giúp code dễ đọc và dễ bảo trì — cho cả người khác và chính bạn sau này.

#### 3. Error Handling (Xử Lý Ngoại Lệ)

**Vấn đề:** Code giả định người dùng luôn nhập đúng

**Giải pháp:** Dùng `try-catch` để xử lý input không hợp lệ

```java
try {
    userAge = scanner.nextInt();
    requestedLoanAmount = scanner.nextDouble();
} catch (InputMismatchException e) {
    System.out.println("Invalid input. Please enter numeric values.");
    scanner.next(); // clear invalid input
    return;
}
```

#### 4. Quản Lý Resource

**Vấn đề:** Quên đóng `Scanner` → rò rỉ tài nguyên

**Giải pháp:** Đóng `Scanner` sau khi sử dụng

```java
scanner.close();
```

## Code Trước Và Sau Khi Cải Thiện

### Code Gốc (Chưa Cải Thiện)

```java
import java.util.Scanner;

public class LoanApplication {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter your age: ");
        int age = scanner.nextInt();
        
        System.out.print("Enter loan amount: ");
        double loanAmount = scanner.nextDouble();
        
        if (age >= 18) {
            System.out.println("Loan approved!");
        } else {
            System.out.println("Loan rejected.");
        }
    }
}
```

**Vấn đề:**
- ❌ Không kiểm tra giá trị nhập (số âm, số 0)
- ❌ Tên biến `age`, `loanAmount` không mô tả rõ
- ❌ Không xử lý input sai (nhập chữ → crash)
- ❌ Không đóng `Scanner` → rò rỉ resource

---

### Code Đã Cải Thiện

```java
import java.util.InputMismatchException;
import java.util.Scanner;

public class LoanApplication {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        try {
            System.out.print("Enter your age: ");
            int userAge = scanner.nextInt();
            
            System.out.print("Enter the loan amount you want: ");
            double requestedLoanAmount = scanner.nextDouble();
            
            // Input validation
            if (userAge < 0 || requestedLoanAmount < 0) {
                System.out.println("Error: Age and loan amount must be positive numbers.");
                return;
            }
            
            // Eligibility check
            if (userAge >= 18) {
                System.out.println("Congratulations! Your loan application has been accepted.");
            } else {
                System.out.println("Sorry, you are not eligible for a loan. You must be at least 18 years old.");
            }
            
        } catch (InputMismatchException e) {
            System.out.println("Error: Please enter valid numeric values.");
            scanner.next(); // Clear invalid input
        } finally {
            scanner.close(); // Clean up resources
        }
    }
}
```

**Cải Tiến:**
- ✅ Kiểm tra giá trị dương
- ✅ Tên biến rõ ràng (`userAge`, `requestedLoanAmount`)
- ✅ Xử lý ngoại lệ với `try-catch`
- ✅ Đóng `Scanner` trong `finally`

**Kết quả:** Code trở nên **robust**, xử lý tốt các edge cases, dễ đọc và dễ bảo trì.
