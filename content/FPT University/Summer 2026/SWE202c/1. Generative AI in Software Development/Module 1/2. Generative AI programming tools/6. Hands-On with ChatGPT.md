## Ví Dụ Thực Tế

### 1. Giải Thích Khái Niệm Java

**Tình huống:** Alex muốn hiểu cách sử dụng **for-each loop** trong Java.

**Prompt:**

> "Can you explain how to use a for-each loop in Java with a simple example?"

**Phản hồi từ ChatGPT:**

For-each loop là phiên bản đơn giản hóa của for loop truyền thống, dùng để duyệt qua các phần tử trong mảng hoặc collection. Nó loại bỏ nhu cầu sử dụng biến index và giúp code sạch hơn.

```java
String[] fruits = {"Apple", "Banana", "Orange"};

for (String fruit : fruits) {
    System.out.println(fruit);
}
```

Ví dụ này cho thấy cách for-each loop duyệt qua từng phần tử trong mảng. Alex thấy dễ hiểu và áp dụng vào dự án của mình.

### 2. Tạo Code Snippet

**Tình huống:** Alex cần đảo ngược một chuỗi (string reversal).

**Prompt:**

> "Could you give me a Java code snippet to reverse a string?"

**Phản hồi từ ChatGPT:**

Sử dụng lớp `StringBuilder` để đảo ngược chuỗi:

```java
public class StringReversal {
    public static void main(String[] args) {
        String original = "Hello World";
        String reversed = new StringBuilder(original).reverse().toString();
        System.out.println("Reversed: " + reversed);
    }
}
```

Phương thức `reverse()` trong `StringBuilder` giúp thao tác chuỗi đơn giản hơn. Alex sử dụng ví dụ này để triển khai nhanh chóng.

### 3. Gỡ Lỗi Code (Debugging)

**Tình huống:** Alex gặp lỗi **NullPointerException** và không hiểu nguyên nhân.

**Prompt:**

> "Why am I getting a NullPointerException in this code?"

**Code snippet bị lỗi:**

```java
public class Main {
    public static void main(String[] args) {
        String str = null;
        System.out.println(str.length()); // Lỗi ở đây
    }
}
```

**Phản hồi từ ChatGPT:**

Lỗi xảy ra vì bạn đang gọi `str.length()` trên một đối tượng null. Trong Java, null đại diện cho tham chiếu chưa được khởi tạo, do đó gọi bất kỳ phương thức nào trên nó sẽ gây ra `NullPointerException`.

**Cách sửa:**

```java
public class Main {
    public static void main(String[] args) {
        String str = null;
        if (str != null) {
            System.out.println(str.length());
        } else {
            System.out.println("String is null");
        }
    }
}
```

Ví dụ này giúp Alex hiểu nguyên nhân lỗi và tránh gặp phải trong tương lai.
