# Amazon Q Developer - Hướng Dẫn Sử Dụng Thực Tế

## Giới Thiệu

**Amazon Q Developer** không chỉ đơn thuần là một công cụ gợi ý mã. Nó là một trợ lý AI được tích hợp trực tiếp vào IDE của bạn, giúp:

- Phát hiện lỗi ngay khi bạn gõ
- Đề xuất cải tiến và tối ưu hóa code
- Hướng dẫn các **best practices**
- Tự động hoàn thiện code theo ngữ cảnh

---

## Ví Dụ Thực Tế: Xây Dựng Máy Tính Đơn Giản (Simple Calculator)

### Yêu Cầu

Tạo chương trình Java nhận hai số từ người dùng và thực hiện các phép toán:
- Phép cộng (Addition)
- Phép trừ (Subtraction)
- Phép nhân (Multiplication)
- Phép chia (Division)
- Phép chia lấy dư (Modulus)

---

## Bước 1: Tạo Code Cơ Bản

Trong IntelliJ, bạn đã tạo dự án **Simple Calculator** với class `Calculator.java`.

**Prompt sử dụng với Amazon Q:**

> "In the Calculator class, create a main method, declare two integers with assigned values, perform addition, subtraction, multiplication, division, and modulus operations, and display the results."

Amazon Q sẽ tạo code gợi ý. Bạn có thể:

- Dùng phím **Next/Previous** để xem các gợi ý khác nhau
- Nhấn **Insert Code** để chấp nhận gợi ý
- Hoặc viết thủ công và để AI tự động hoàn thiện

```java
public static void main(String[] args) {
    int num1 = 10;
    int num2 = 5;
    
    int sum = num1 + num2;
    int difference = num1 - num2;
    int product = num1 * num2;
    int quotient = num1 / num2;
    int remainder = num1 % num2;
    
    System.out.println("Sum: " + sum);
    System.out.println("Difference: " + difference);
    System.out.println("Product: " + product);
    System.out.println("Quotient: " + quotient);
    System.out.println("Remainder: " + remainder);
}
```

> [!note] LƯU Ý
> Kết quả từ Amazon Q dựa trên dữ liệu đã học, bạn có thể cần điều chỉnh nhẹ để phù hợp với yêu cầu cụ thể.

## Bước 2: Làm Cho Chương Trình Động (Dynamic Input)

Vấn đề của code trên là **giá trị cố định**, không nhận input từ người dùng.

### Cập nhật code để sử dụng Scanner

```java
import java.util.Scanner;

public class Calculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter first number: ");
        int num1 = scanner.nextInt();
        
        System.out.print("Enter second number: ");
        int num2 = scanner.nextInt();
        
        // Các phép toán tương tự như trên
        // ...
    }
}
```

> [!tip] TÍNH NĂNG CỦA AMAZON Q
> Khi bạn gõ `Scanner`, Amazon Q sẽ tự động:
> - Phát hiện ngữ cảnh và đề xuất code setup Scanner
> - Gợi ý import `java.util.Scanner` nếu bạn quên

---

## Bước 3: Best Practices - Đóng Scanner

Nếu bạn quên đóng `Scanner` để giải phóng tài nguyên, Amazon Q sẽ phát hiện và đề xuất:

```java
scanner.close();
```

> [!warning] QUAN TRỌNG
> Luôn đóng các resource như `Scanner`, `Connection`, `Stream` để tránh rò rỉ bộ nhớ.

---

## Bước 4: Xử Lý Lỗi - Chia Cho 0

**Vấn đề:** Nếu người dùng nhập số chia là 0, chương trình sẽ crash.

Amazon Q phát hiện rủi ro này và đề xuất thêm điều kiện kiểm tra:

```java
if (num2 != 0) {
    int quotient = num1 / num2;
    int remainder = num1 % num2;
    System.out.println("Quotient: " + quotient);
    System.out.println("Remainder: " + remainder);
} else {
    System.out.println("Cannot divide by zero!");
}
```
